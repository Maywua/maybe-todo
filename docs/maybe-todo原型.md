# maybe-todo 原型（v1 定稿）

> 在原始原型基础上回填 16 项产品决策后的可实施版本。
> 目标平台：Windows 桌面（Tauri 2）。v1 只做桌面，移动端不在范围内。

## 0.1 相对原型的修正（消歧义）

- 加号按钮：悬停展开菜单，点击也可打开；`+` 永远不直接开浮窗。
- 新建模式的功能菜单：未落库前不显示；首次保存成功后显示（这时才可锁定/删除）。
- 删除 = 移入回收站，浮窗关闭并轻提示，不再硬删除。
- 内部时间统一为毫秒时间戳；界面显示 `YY-MM-DD HH:mm`（本地时区）。
- 类型改为字符串枚举；术语统一为「待办」。
- 列表顺序由 `order` 字段决定，新建便签置顶；不再按修改时间排。
- 首页改为四列瀑布流；类型筛选、拖拽排序暂缓，卡片只显示标题和内容。
- 锁定只读：禁改标题/内容，仍可删除。
- 移除首页的全局快速输入框，`Ctrl+K` 一并移除。

# 实体（entity）

## 便签（note）

### ID

- 字符串，UUID v4，创建时生成，不可更改。

### 类型（type）

- 字符串枚举：`"text"` 为笔记，`"todo"` 为待办。
- 创建后不可切换类型（笔记↔待办转换不在 v1 范围）。
- 读到未知类型时按 `"text"` 只读处理，不丢数据。

### 标题（title）

- 字符串，长度为 0 到 30 个「用户可见字符」（Unicode 字素：中文、英文、emoji 都算 1 个）。
- 保存时去除首尾空白；内部空格保留。
- 可为空，为空时界面显示「未命名」。
- 输入时硬限制 30 个字符，粘贴超长自动截断并提示；长度达到 25 时显示 `n/30` 计数。

### 内容（content）

- 对象类型，数据格式由 `type` 决定，详见「内容格式」一节。
- 对象内带 `version` 字段，用于以后迁移内容结构。
- 内容为空是合法的（标题可以单独存在）。

### 排序（order）

- 数字（浮点），升序排列，值越小越靠上。
- 新建便签排在最前：`order = 当前最小值 - 1`。
- 当前版本只按 `order` 升序展示，不提供拖拽排序；后续加回手动排序时，拖到两条之间取相邻两值的中点，间距小于 `1e-6` 时对全表重新编号。
- 排序变化不更新「修改时间」。

### 创建时间（createdAt）

- 毫秒时间戳（Unix ms），首次保存时记录，不可更改。

### 修改时间（updatedAt）

- 毫秒时间戳，仅当标题或内容实际发生变化时更新。
- 锁定、排序变化、移入/移出回收站都不更新此字段。
- 保存时先比对内容快照，无变化则不写库、不更新时间。

### 删除时间（trashedAt）

- 毫秒时间戳或空。空表示正常便签。
- 有值表示已进入回收站，并作为 30 天后彻底删除的判断依据。
- 回收站恢复时清空此字段，其余字段保持原样。

### 完成时间（completedAt）

- 毫秒时间戳或空，仅待办使用。
- 子项数量大于 0 且全部勾选时，记为当前时间；取消任一子项、新增未勾选子项时清空。
- 由保存逻辑自动计算，不允许手动修改。
- 没有子项的待办 `completedAt` 恒为空，卡片不显示完成态。

### 已锁定（isLocked）

- 布尔类型。
- 为 `true` 时标题和内容不可编辑，仍可删除、移入回收站。
- 详情浮窗显示「已锁定」提示；当前版本的卡片只显示标题和内容，不显示锁图标。
- 锁定不是加密，数据仍以明文存储。

## 字段命名映射

文档保留中文名，JSON / 数据库统一使用 camelCase（数据库列为 snake_case）。

| 中文名 | JSON / TS | 数据库列 |
| --- | --- | --- |
| ID | `id` | `id` |
| 类型 | `type` | `type` |
| 标题 | `title` | `title` |
| 内容 | `content` | `content`（JSON 文本） |
| 排序 | `order` | `order_index` |
| 创建时间 | `createdAt` | `created_at` |
| 修改时间 | `updatedAt` | `updated_at` |
| 删除时间 | `trashedAt` | `trashed_at` |
| 完成时间 | `completedAt` | `completed_at` |
| 已锁定 | `isLocked` | `is_locked` |

## 内容格式

### 笔记（type = "text"）

```json
{ "version": 1, "format": "plain", "text": "随便写点什么" }
```

- `format` 目前固定为 `"plain"`，纯文本，不支持 Markdown / 富文本 / 图片。
- 文本上限 20,000 个字符，粘贴超长截断并提示。
- 不保留首尾空白之外的格式；换行原样保留。

### 待办（type = "todo"）

```json
{
  "version": 1,
  "format": "checklist",
  "items": [
    { "id": "uuid", "text": "买牛奶", "done": true, "doneAt": 1762312345678 },
    { "id": "uuid", "text": "取快递", "done": false, "doneAt": null }
  ]
}
```

- `items` 为子项数组，最多 99 项；每项文本 1 到 200 个字符。
- 允许只有一条子项，也允许 0 条（只有标题的待办，视为备忘）。
- 子项勾选时写 `doneAt`，取消时置空。
- 保存时丢弃文本为空白的子项；界面上至少保留一个输入行。
- 子项可拖动？v1 不做子项排序，按创建顺序显示。

## 数据存储

- 目标：SQLite 单库 `maybe-todo.db`，放在系统应用数据目录（Tauri `appDataDir`）。
- 当前实现（v0.2）：本地 JSON 文件 `maybe-todo.json`，结构 `{ version, notes }`，先写临时文件再替换，并保留上一版 `.bak`；实体字段与命令接口按上面的定义，迁移到 SQLite 时前端不需要改。
- 版本迁移使用版本号；读到高于当前支持的版本时拒绝加载，不覆盖原文件。
- 前端不直接读写文件，统一走 Rust 侧的存储命令；浏览器预览时才退回 localStorage。
- 不设便签数量上限；不按 200 条截断。

### 自动备份

- 启动时检查距上次备份是否满 24 小时，满则把当前数据库复制到 `backups/` 目录。
- 备份文件名 `maybe-todo-YYYYMMDD-HHmmss.db`，保留最近 7 份，多余的旧备份删除。
- 备份使用 SQLite 的一致性快照方式（如 `VACUUM INTO`），不直接复制正在写入的库文件。
- 备份失败时在首页顶部显示一条可关闭的提示，不阻塞使用。
- v1 不提供导出/导入界面，备份文件是唯一的手动迁移途径。

### 回收站清理

- 仅在应用启动时执行一次：删除 `trashedAt` 早于「当前时间 − 30 天」的便签。
- 应用长时间不关闭时，不在运行中清理；下次启动再处理。
- 系统时间被改到过去会导致清理延后，不做额外补偿。

# 界面（pages）

## 启动页

- 启动时展示，居中显示应用图标和名称，无其它内容。
- 展示期间并行完成：打开数据库、执行迁移、清理过期回收站、按需备份。
- 最短显示 300ms（防闪烁），最长 1.5s；数据就绪即结束。
- 超过 1.5s 仍未就绪时直接进入首页，首页显示骨架屏。
- 点击或按任意键可跳过（但不早于 300ms）。
- 尊重系统「减少动态效果」设置：开启时不做淡入淡出。
- 桌面端窗口在前端就绪前保持隐藏，避免先看到白屏再看到启动页。

## 首页

- 结构从上到下：标题栏、四列瀑布流。
- 窗口最小尺寸 760 × 560。

### 标题栏

- 固定高度（约 56px），整宽。
- 左侧：功能菜单按钮（图标三条横杠）。
- 中间：留白，不显示应用名。
- 右侧：添加便签按钮（图标加号）。

### 便签瀑布流

- 四列固定列宽，内容区最大宽度 1024px 居中，列间距 12px；不使用等高行。
- 按 `order` 升序，依次轮转分配到四列：第 1、5、9… 条进第一列，第 2、6、10… 条进第二列，依此类推。
- 每列独立纵向堆叠，卡片高度各自随标题和内容增长，列底不强制对齐。
- 当前版本不提供类型筛选和拖拽排序，筛选功能后续再加。
- 没有便签数量上限；超过一屏后内容区独立滚动。

#### 卡片样式

- 黄色便签，圆角，内边距约 16px；高度不固定，由标题和内容自然撑开。
- 上方标题：最多两行，超出省略号；空标题显示「未命名」。
- 下方内容区域：显示正文或子项，最多 8 行，超出省略号；正文编辑尚未实现时内容为空，保留一块空白区域。
- 卡片只显示标题和内容，不显示类型、进度、锁图标、时间。

#### 卡片状态

- 默认、悬停（上浮、阴影加深）、键盘聚焦（焦点环）。
- 卡片是可聚焦元素：`Enter` 打开详情，`Tab` 在卡片间移动。

#### 空状态

- 一条便签都没有：「先记下来，再决定」 + 「新建笔记」「新建待办」两个按钮。
- 数据库读取失败：错误卡片，包含原因、「重试」、「打开数据目录」，并保留原库不做任何覆盖。

### 添加便签按钮

- 标题栏右侧。
- 鼠标悬停展开菜单；点击按钮也打开，点击外部或按 `Esc` 关闭。
- 菜单选项：新建笔记、新建待办。
- 选择后打开便签详情浮窗，进入新建模式，并带上所选类型。
- 键盘：聚焦按钮后按 `Enter` 展开菜单，方向键选择，`Enter` 确认，`Esc` 关闭。
- `+` 本身永远不直接打开浮窗。

### 功能菜单

- 标题栏左侧，鼠标悬停展开；点击按钮也打开，点击外部或按 `Esc` 关闭。
- 选项：
  - 首页：回到首页；已在首页时置灰。
  - 设置：v1 不实现，置灰，悬停提示「v1 暂未提供」。
  - 回收站：打开回收站页。
  - 关于：v1 不实现，置灰，悬停提示「v1 暂未提供」。
  - 退出：保存未落盘内容后退出应用。
- 点击菜单外部或按 `Esc` 关闭。
- 菜单项可 Tab 聚焦，方向键移动。

## 回收站页

- 入口：功能菜单 → 回收站。
- 标题栏：左侧返回按钮（回到首页），中间标题「回收站」，右侧「清空」按钮。
- 列表按 `trashedAt` 倒序，样式沿用便签卡片但整体降饱和度。
- 每行显示：
  - 标题（空则「未命名」），锁定便签带锁图标。
  - 一行缩略内容（规则同首页）。
  - 「删除于 26-10-30 14:00 · 29 天后删除」。
  - 「恢复」「彻底删除」两个按钮。
- 恢复：清空 `trashedAt`，保留原 `order`；若与现有便签排序冲突，则放到列表最前。恢复后提示「已恢复」。
- 彻底删除：二次确认「彻底删除后无法恢复」，确认后删除。
- 清空：二次确认「清空回收站？共 N 条，删除后无法恢复」，确认后清空全部。
- 空状态：「回收站是空的」 + 「返回首页」按钮。
- 回收站内不可打开详情、不可编辑；锁定状态保留，恢复后仍是锁定。

# 组件（components）

## 便签详情浮窗

### 打开方式与模式

- 点击便签卡片、或从添加菜单选择类型时打开。
- 编辑模式：传入便签 `id`，内容从数据层读取，不从列表拷贝，避免列表与浮窗数据不一致。
- 新建模式：不传 `id`，带类型进入；首次保存成功时创建记录并生成 `id`。
- 同一时间只允许一个浮窗；打开另一个前先保存并关闭当前。
- 新建模式下未落库前，功能菜单隐藏；首次保存成功后菜单出现。
- 浮窗带遮罩，居中显示，宽度 640px，最大高度 80vh，内容区超出后内部滚动。

### 窗口标题行

- 左侧：便签功能菜单（三条横杠），新建且未落库时不显示。
- 右侧：关闭按钮。
- 编辑模式下，锁定便签在标题行显示锁图标和「已锁定」提示。

### 标题行

- 单行输入框，占位符「未命名」，字号明显大于内容。
- 30 个字符上限；长度达到 25 时在右侧显示 `n/30`。
- 新建模式打开后自动聚焦标题并全选（如有）。

### 内容区域：笔记

- 多行纯文本输入框，随内容自动增高，最大高度 50vh 后内部滚动。
- 支持换行，不支持任何富文本格式。

### 内容区域：待办

- 每行一个子项：勾选框、文本输入框、删除该行的按钮（悬停显示）。
- 子项文本上限 200 字符。
- `Enter` 在当前子项后新增一行并聚焦；空行按 `Backspace` 删除该行；输入框内至少保留一行。
- 底部「+ 添加子项」按钮。
- 顶部显示进度「2/3 已完成」；全部完成时显示「已完成」。
- 勾选/取消勾选立即触发保存。

### 保存规则

- 自动保存，无保存按钮。
- 输入停止 500ms 后落库；切换焦点、关闭浮窗、关闭应用时立即落盘（flush）。
- 保存成功后标题/内容快照更新，用于下次比对。
- 只有标题或内容实际变化才写入，且更新 `updatedAt`。
- 保存状态显示在浮窗底部左侧：
  - 保存中：「保存中…」
  - 成功：「已保存 14:03」
  - 失败：「保存失败，点击重试」，内容保留在内存中。
- 新建模式：
  - 标题和内容都为空时关闭，不创建记录。
  - 首次输入有效内容时创建记录，`order` 取当前最小值 − 1，`createdAt` 为当前时间。
- 编辑模式：
  - 标题清空后保存为「未命名」，不删除便签。
  - 内容清空后保存为空内容，不删除便签。
  - 清空全部待办子项后保存为 0 子项（只有标题）。
- 关闭失败保护：保存失败时关闭浮窗，先阻止关闭并提示重试，避免丢编辑内容。
- 关闭浮窗 = 保存并关闭；没有「放弃修改」路径。
- 全局撤销不做（决策 5），输入框内可使用系统原生撤销。

### 锁定

- 功能菜单内「锁定」为开关，切换后立即保存并写库。
- 锁定时：标题、内容、子项输入框全部禁用，勾选框禁用。
- 锁定不阻止删除、不影响回收站恢复。
- 解锁后恢复编辑。

### 删除

- 功能菜单内「删除」，点击后：
  - 便签移入回收站（写 `trashedAt`），浮窗关闭。
  - 轻提示「已移入回收站」，持续 2 秒，不提供撤销按钮。
- 不弹二次确认（有回收站兜底）。
- 新建且从未落库的便签没有删除项（菜单不显示）。

### 关闭与焦点

- 关闭方式：关闭按钮、`Esc`、点击遮罩，三者行为一致，都是保存并关闭。
- 关闭后焦点回到打开前的卡片；卡片已被删除时回到列表。
- 浮窗内焦点陷阱，`Tab` 不跳出浮窗。
- 浮窗底部右侧显示「创建于 26-11-05 12:00 · 修改于 26-11-05 12:03」，新建模式只显示创建时间（首次保存后）。

## 轻提示（toast）

- 底部居中，深色底浅色字，2 秒自动消失，不遮挡操作。
- 用途：已移入回收站、已恢复、标题/内容超长截断提示。
- 同一时间只显示一条，新提示替换旧提示。

## 确认对话框

- 用于「彻底删除」「清空回收站」。
- 标题 + 说明 + 「取消」「确认删除」两个按钮。
- 默认焦点在「取消」；`Esc` 取消。

# 交互规则

## 鼠标

- 悬停展开菜单；点击按钮也打开；点击外部或按 `Esc` 关闭。
- 点击卡片打开浮窗。
- 关闭浮窗的三种方式行为一致。

## 键盘

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + N` | 打开添加菜单，聚焦「新建笔记」 |
| `Ctrl/Cmd + Enter` | 保存并关闭当前浮窗 |
| `Esc` | 关闭菜单 / 取消确认框 / 保存并关闭浮窗 |
| `Enter` | 在聚焦的卡片上打开详情 |
| `Tab` / `Shift + Tab` | 在元素间移动；浮窗内循环 |
| `↑` / `↓` | 在菜单中移动选项 |
| `Enter` / `Space` | 确认菜单项、勾选子项 |

- 当前版本不提供键盘排序，菜单方向键导航也留待后续。

## 可访问性

- 所有图标按钮带 `aria-label`；菜单使用 `role="menu"` / `menuitem`。
- 浮窗使用 `role="dialog"` + `aria-modal="true"`，标题与描述关联。
- 焦点可见（焦点环），颜色对比度满足正文可读。
- 支持系统「减少动态效果」：关闭淡入、滑入、插入线动画。
- 仅浅色主题；v1 不做深色模式和字号档位。

## 异常处理

- 数据库打开失败：首页显示错误卡片（原因、重试、打开数据目录），不覆盖、不重建数据库。
- 数据库内容损坏：保留原文件，提示「可从最近备份恢复」；恢复前把坏库改名为 `.corrupt` 留档。
- 保存失败：浮窗内提示可重试，关闭前再次尝试，失败则阻止关闭。
- 备份失败：首页顶部可关闭的提示条。
- localStorage 预览模式容量不足：提示「浏览器预览存储已满，请改用桌面端」；桌面端不适用。

# 验收标准

1. 冷启动到首页 ≤ 800ms（不含启动页最短 300ms）。
2. 新建笔记、新建待办、编辑、锁定、删除、恢复、彻底删除全流程可完成，可纯键盘操作。
3. 关闭应用再打开，数据、排序、锁定状态、回收站内容全部保留。
4. 30 天前的回收站便签在启动时被清理，30 天内的保留。
5. 自动备份按 24 小时节流生成，最多保留 7 份。
6. 2000 条便签下瀑布流滚动不掉帧。
7. 保存失败、数据库损坏、备份失败三种异常都有明确提示，且不静默丢数据。
8. 所有空状态、加载状态、错误状态都有界面。

# 附录 A：与现有 v0.1 代码的差异

- `Note = { id, text, done, createdAt }` 需替换为本文实体；需要一次数据迁移。
- 首页当前的营销落地页（大标题、卖点、状态卡）与原型首页不一致，需改为四列瀑布流。
- `useNotes` 中的 `slice(0, 200)` 静默截断必须去掉。
- `loadNotes` 解析失败返回示例数据的逻辑必须改为报错并保留原文件。
- 快速输入框与 `Ctrl+K` 移除；新建统一走添加菜单。
- localStorage 仅保留为浏览器预览的降级方案，桌面端使用本地 JSON 文件（后续可替换 SQLite）。
- 现有 2 条 seed 便签在正式版中移除。

# 附录 B：字段速查

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 否 | UUID v4 |
| `type` | `"text" \| "todo"` | 否 | 创建后不可变 |
| `title` | string | 是 | 0–30 字素，空显示「未命名」 |
| `content` | object | 否 | 按类型，含 `version` |
| `order` | number | 否 | 升序，越小越靠前 |
| `createdAt` | number | 否 | Unix ms |
| `updatedAt` | number | 否 | 仅标题/内容变化时更新 |
| `trashedAt` | number | 是 | 非空表示在回收站 |
| `completedAt` | number | 是 | 仅待办，全部子项完成时写入 |
| `isLocked` | boolean | 否 | 只读标记 |
